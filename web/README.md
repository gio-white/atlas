# Atlas web UI

The Atlas frontend: a React SPA. It talks only to the HTTP API; derived values (streaks, adherence, pace) stay on the server. There is no CLI review UI.

Package manager is pnpm. Linter and formatter is Biome. How to run it is in the [root README](../README.md). Routes, hosting, and the API contract live in [docs/architecture.md](../docs/architecture.md).
